# Демо-кейсы для питча

## Кейс 1: Латентный дефицит железа при нормальном гемоглобине

**Пациент:** P000269

**Что видит врач по ОАК:**
- Гемоглобин: 158.3 г/л (норма)
- MCV: 88.7 фл (норма)
- RDW: 14.5% (норма)

**Вывод врача по ОАК:** «Все показатели в норме, пациент здоров».

**Что находит модель:**
- Прогноз: `latent_deficiency` (латентный дефицит железа)
- Уверенность: 82%

**Ключевые показатели, которые заметила модель:**
- Ферритин: 20.6 нг/мл (норма ≥ 30) — ниже порога
- TSAT: 12.2% (норма ≥ 20) — ниже порога
- Сывороточное железо: 8.2 мкмоль/л — низкое
- Ret-He: 23.5 пг (норма ≥ 28) — снижен

**Причина решения (топ-5 SHAP):**
- ferritin = 20.6 → вклад +0.06
- TSAT = 12.2 → вклад +0.07
- serum_iron = 8.2 → вклад (в топ)
- Ret_He = 23.5 → вклад (в топ)

**Ценность:** модель ловит скрытый дефицит до развития анемии. Врач по ОАК пропустил бы. Модель рекомендует дообследование (ферритин, TSAT, ОЖСС).

## Кейс 2: Сочетанный дефицит железа и B12

**Пациент:** P000079

**Что видит врач по ОАК:**
- Гемоглобин: 89.6 г/л (анемия)
- MCV: 85.1 фл (НОРМА — псевдонормоцитоз!)
- RDW: 18.6% (повышен)

**Сложность:** MCV нормальный, хотя у пациента ДВА дефицита. Fe-дефицит даёт микроцитоз, B12 — макроцитоз. Они нивелируют друг друга → MCV норма. Изолированный анализ ОАК → диагностическая ошибка.

**Что находит модель:**
- Прогноз: `mixed_deficiency` (сочетанный Fe + B12)
- Уверенность: 81%

**Ключевые показатели:**
- Ферритин: 9.7 нг/мл (норма ≥ 15) — явный ЖД
- TSAT: 4.2% (норма ≥ 20) — очень низкий
- Витамин B12: 103 пг/мл (норма ≥ 200) — дефицит
- Сывороточное железо: 3.6 мкмоль/л — низкое
- Фолаты: 3.8 нг/мл — граница
- CRP: 3.1 мг/л — норма
- ESR: 11 мм/ч — норма

**Причина решения (топ-5 SHAP):**
- vitamin_B12 = 103 → вклад +0.05
- TSAT = 4.2 → вклад +0.05
- ferritin = 9.7 → вклад +0.04
- low_TSAT = 1 → вклад +0.04

**Ценность:** модель видит ОБА дефицита, которые маскируют друг друга в MCV. Врач по ОАК не определил бы сочетанный характер.

## Кейс 3: Анемия воспаления (ферритин ложно высокий)

**Пациент:** P000497

**Что видит врач по ОАК:**
- Гемоглобин: 99.9 г/л (анемия)
- Ферритин: 198.7 нг/мл (норма) — ложно высокий!
- CRP: 180 мг/л (рекордно высокий)
- ESR: 110 мм/ч (рекордно высокий)

**Сложность:** ферритин — острофазный белок. При воспалении ложно повышается. Изолированный анализ ферритина → ошибка («ферритин в норме → нет ЖД»).

**Что находит модель:**
- Прогноз: `inflammation_anemia`
- Уверенность: 64%

**Ключевые показатели:**
- CRP: 180 мг/л (норма < 5) — сильнейшее воспаление
- ESR: 110 мм/ч (норма < 20) — подтверждение
- sTfR: 1.11 мг/л (норма 1.8–4.6) — низкий (при ЖД — высокий)
- Витамин B12: 430 пг/мл — норма

**Причина решения (топ-5 SHAP):**
- CRP = 180 → вклад +0.16
- ESR = 110 → вклад +0.15
- inflammation_flag = 1 → вклад +0.02
- ferritin = 198.7 → вклад +0.02

**Ценность:** модель не путает воспаление с истинным ЖД, несмотря на высокий ферритин. Врач, глядя только на ферритин, ошибся бы.

## Ограничение: ошибка модели

**Пациент:** P000090

**Что видит врач по ОАК:**
- Гемоглобин: 140.8 г/л (норма)
- MCV: 93.6 фл (норма)
- RDW: 13.0% (норма)

**Реальный диагноз:** `latent_deficiency`

**Прогноз модели:** `no_anemia_no_deficiency` (ошибка)

**Причина:** ферритин 35.9 — выше нашего порога `< 30`. Модель права по формальному правилу, но клинически у пациента латентный ЖД.

**Решение:** расширить порог до `ferritin < 50` для более чувствительного скрининга латентного дефицита. Либо учитывать тренд ферритина (у нас нет временных данных).
