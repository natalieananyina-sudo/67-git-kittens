# Сценарий живой демонстрации (3–4 минуты)

Подготовка: запустите сервис (`docker compose up --build` или `scripts/dev.sh`), откройте его в браузере,
держите под рукой папку `data/demo`. Убедитесь, что над результатами нет предупреждения «Демонстрационный режим»:
значит, работает финальная модель (то же видно в `/api/v1/health`).

1. **Вход.** Покажите экран входа (растущая сеть сосудов). Введите неверный пароль — появится ошибка.
   Затем войдите: `doctor_demo` / `y7pr-gHXm-Pb9w`.
2. **Выбор режима.** Приветственный экран с двумя режимами. Выберите «Много пациентов».
3. **Пакетная обработка.** Загрузите `01_showcase_all_classes.csv` — 24 пациента, по два на каждый из
   12 классов. Покажите сводку, фильтры и столбец «Причина по модели». Ответы: `data/demo/answers/01_answers.csv`.
4. **Проверка формата.** Загрузите `04_with_format_errors.csv`. Сервис укажет строку и столбец каждой ошибки
   (гемоглобин в г/дл, возраст 16, неизвестный пол, «<0,5» вместо числа, текст вместо числа, повтор ID)
   и обработает корректные строки. Строка без гемоглобина — не ошибка формата: модель вернёт для неё
   «Недостаточно данных».
5. **Единицы измерения.** Загрузите `05_other_units.csv` (гемоглобин в г/дл, B12 в пмоль/л и др.) —
   сервис сообщит, какие столбцы переведены в стандартные единицы.
6. **Карточка пациента.** Откройте строку с сочетанным дефицитом: вкладка «Для врача» (правило анемии,
   причина по модели и её оценки — не вероятности, обследования), затем «Для пациента» и «Распечатать».
7. **Один пациент.** Переключите режим вкладкой сверху. Загрузите `single/02_iron_deficiency_anemia.csv`,
   затем `single/09_insufficient_data.csv` (модель объясняет, каких панелей анализов не хватает),
   затем `single/08_with_errors.csv` (ошибки формата) и покажите «Ввести показатели вручную».
8. **Реалистичная картина (по желанию).** Загрузите `02_clinic_day_representative.csv` или
   `03_screening_large.xlsx` (600 пациентов, 10–15 с): около трети строк — «Недостаточно данных», как и в
   исходном датасете. Откройте `/docs` — REST API для подключения МИС/ЛИС.
